# V5.11 — UX integration gate

This stage began only after the V5.10 UI gate passed on Windows, Ubuntu and all CodeQL lanes.
It focuses on finding things, recovering from filters, preserving useful state, keyboard discoverability,
and moving around long pages. It does not remove or rename any content route.

| uswds/uswds | Straightforward navigation, touch-friendly controls, and visible system state. |
| w3c/aria-practices | Keyboard discoverability, current-state semantics, and focus continuity. |

## Implemented

- Filter boards now have stable keys and keep query/category/sort state in the URL.
- Reloading a filtered page restores its valid state; invalid option values are ignored.
- Clear filters removes only that board's URL parameters and preserves unrelated parameters.
- Result counts, existing empty states, and reset controls remain synchronized.
- The already-supported Ctrl/Cmd+K search shortcut is now discoverable in the header and exposed via `aria-keyshortcuts`.
- Long pages gain a progressive Back to top control that appears only after scrolling.
- Back-to-top respects reduced-motion preferences and does not exist as a required navigation path.
- Empty filtered results give a direct recovery instruction.
- Runtime tests cover URL persistence/restoration, reset cleanup, shortcut discoverability, and long-page recovery.

No analytics, tracking, account state, or external UX runtime was introduced.
