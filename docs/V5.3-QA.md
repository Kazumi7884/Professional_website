# V5.3 quality guidance

The current site remains a small static Python/Jinja/Markdown build. The
following projects were reviewed as patterns, not dependencies:

| Project | Guidance used |
| --- | --- |
| [Primer CSS](https://github.com/primer/css) | durable tokens, component states and restrained density |
| [Playwright](https://github.com/microsoft/playwright) | viewport matrix and real browser interaction testing |
| [Pa11y](https://github.com/pa11y/pa11y) | accessibility assertions and keyboard-first review |
| [Meilisearch](https://github.com/meilisearch/meilisearch) | predictable local search indexing and ranking expectations |
| [Decap CMS](https://github.com/decaporg/decap-cms) | editorial metadata and draft workflow ideas without adding remote auth |
| [Storybook](https://github.com/storybookjs/storybook) | isolated component thinking for boards, cards and controls |
| [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) | consistent spacing/token discipline, without adding a utility framework |
| [Python-Markdown](https://github.com/Python-Markdown/markdown) | production Markdown extension consistency |
| [Jinja](https://github.com/pallets/jinja) | small reusable template macros and safe escaping |
| [Lighthouse](https://github.com/GoogleChrome/lighthouse) | performance, SEO and accessibility audit priorities |

## Verification floor

Every implementation pass must run at least 20 automated tests when frontier
models are not being used. This pass exceeds that floor: the Python suite has
66 tests, in addition to the generated-site audit and JavaScript syntax gates.

## Viewport contract

Responsive checks cover mobile (390×844), 4:3 (1024×768), 5:4 (1280×1024),
21:9 (2560×1080), and 32:9 (5120×1440). The checks enforce viewport metadata,
fluid columns, readable ultrawide shells, scrollable tables/code, mobile card
stacking, and touch-sized controls. They are static contracts; browser
screenshots remain a useful follow-up when a browser runner is available.

## Search contract

Search uses the generated same-origin `search-index.json`, ranks title matches
above body matches, updates the query URL, ignores stale responses, renders
results with DOM text APIs, and provides retryable failure states.
