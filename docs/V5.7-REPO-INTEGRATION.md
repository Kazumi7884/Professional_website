# V5.7 — fifteen-repository integration pass

Reviewed and integrated on 29 September 2026 against `Kazumi7884/Professional_website`.

This pass treats upstream projects as engineering references unless a dependency is genuinely justified.
The public site remains plain generated HTML, external CSS and external JavaScript. It does not load a
framework, hosted font, CDN search library, analytics bundle or third-party runtime.

No source code was copied from the projects below. Their established patterns were adapted to the site's
existing Python/Jinja/Markdown architecture and covered by this repository's own tests.

## User-facing changes

### Search

The search page still works entirely from `/search-index.json`, but its behavior is now closer to a
purpose-built static search engine:

- exact words and title/tag matches rank highest;
- prefixes work, so an incomplete technical term can still find the intended page;
- quoted phrases must occur together and receive a strong relevance boost;
- one small typo is tolerated in title/tag words when the word is long enough to make that safe;
- title and description matches are highlighted with real DOM text nodes, never `innerHTML`;
- typing two or more characters triggers a short debounced search, while Enter/submit still works;
- a versioned local cache remains available when the current index cannot be fetched;
- the search field explains the supported behavior and is linked to that help using `aria-describedby`.

### Offline behavior

The old service worker used one network-first rule for every GET and deleted every cache on the origin
except its own. V5.7 is narrower and safer:

- only same-origin GET requests within this site's scope are handled;
- navigation and the search index use network-first behavior so authored content stays fresh;
- CSS, JavaScript, images and fonts use stale-while-revalidate behavior;
- Range requests are left to the browser/network;
- cache cleanup only removes old `kaz-notebook-*` caches;
- navigation falls back to a cached page or `/offline.html`;
- core and runtime caches are versioned separately.

### Rendering and controls

The first homepage content image is the likely visual/LCP candidate, so it is emitted with
`loading="eager"` and `fetchpriority="high"`. Other generated images keep lazy loading and async
decoding. The stylesheet also gains a small normalization layer, disabled-control behavior, stronger
high-contrast handling and clearer highlighted search matches.

## Dependency decision

None of these fifteen projects became a public runtime dependency. That is deliberate. The current site
is small enough that installing Pagefind, Fuse, Pico, Open Props, Workbox and multiple validators at once
would duplicate functionality and make local/phone/OneDrive maintenance worse. V5.7 takes the useful
behavior while preserving the site's small stack.
