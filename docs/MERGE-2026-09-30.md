# Consolidation — 2026-09-30

This tree consolidates the strongest verified source material from the V5/non-Hugo local site, the V6 authoring snapshot, and the September 30 Codex review work.

## Canonical decisions
- The repository remains non-Hugo. Hugo configuration, generated resources, `node_modules`, caches, virtual environments, build output, and Git metadata are excluded.
- The newer non-Hugo implementation and QA/tooling are the technical baseline.
- Complete authored content from the local site is preserved.
- Seven V6-only authored pages were restored: contact, education, experience, skills, technical-blog index, Kaz Website V6 project, and Steam Library Visualisation project.
- V6 static images absent from the non-Hugo tree were retained for content parity.
- The experimental `successor/` implementation was not promoted as canonical because its visual treatment was not accepted. Its useful QA/maintenance ideas remain represented by the integrated root tooling/docs.

## Preservation rule
Future redesigns must not remove a valid learning, personal, blog, project, or authored-content destination merely to simplify navigation. Redirect or migrate it instead.
