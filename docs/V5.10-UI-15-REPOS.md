# V5.10 — UI integration gate

This stage began only after the V5.9 design gate passed on Windows, Ubuntu and CodeQL.
It changes component affordances and state presentation without changing page routes,
authored content, backend behavior, or the V5.9 theme-token system.

| Repository | UI pattern applied |
| --- | --- |
| radix-ui/primitives | Explicit open/closed component state and accessible disclosure relationships. |
| ariakit/ariakit | Keyboard-visible disclosure state and focus-safe controls. |
| tailwindlabs/headlessui | Behaviour/state separated from visual styling through data/ARIA attributes. |
| adobe/react-spectrum | Disabled, focus-visible, pressed and selection states stay unambiguous. |
| reach/reach-ui | Progressive disclosure remains usable with keyboard and without custom ARIA menu semantics. |
| floating-ui/floating-ui | Popover/submenu appearance is treated as a bounded floating layer, with mobile fallback. |
| ing-bank/lion | Native form controls are enhanced rather than replaced. |
| shadcn-ui/ui | Compact composable control groups and clear reset affordances. |
| chakra-ui/chakra-ui | Consistent interaction-state styling across button-like controls. |
| mui/material-ui | Form controls explicitly describe the content region they update. |
| ant-design/ant-design | Filter/reset/status actions are grouped and visually legible. |
| mantinedev/mantine | Search/filter controls keep touch-friendly sizing and responsive reflow. |
| heroui-inc/heroui | Current/selected navigation gets a distinct state without hiding link semantics. |
| primer/react | Dense navigation and utility controls retain strong focus/current indicators. |
| microsoft/fluentui | Interactive surfaces use consistent hover, active, disabled and focus feedback. |

## Implemented

- Navigation disclosure buttons now expose `aria-haspopup` and synchronized `data-state` values.
- Submenu links show the current page/location.
- Filter controls now identify the list they update using `aria-controls`.
- Reusable Clear filters controls were added to notebook boards, anime filters, and chart filters.
- Filter reset restores query/category/sort defaults, updates result counts, and returns focus to the first control.
- Active filter state is exposed with `data-filter-state` for deterministic UI styling/testing.
- Component focus, expanded, pressed, disabled and current states have consistent visual feedback.
- Personal tabs become horizontally scrollable rather than wrapping into an awkward mobile block.
- Runtime tests cover disclosure state, current submenu state, reset behaviour, and control/list relationships.

No UI framework or component runtime was added to the public site.
