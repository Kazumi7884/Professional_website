# Kaz's clean-room successor

The site has two jobs. The personal side is a place for posts, games, anime and
ordinary updates. The work side is a clear record of courses, notes and project
evidence. It should feel like one person's site, rather than a portfolio template
with a blog attached.

The writing uses the plain, first-person tone already present in the published
posts: direct, a little informal, and specific about what is known. It does not
turn course progress into confidence ratings or make a small piece of work sound
like a product launch. Authored Markdown remains the source for personal voice.

The default theme is called **Forum**. It borrows the density and wayfinding of a
good old personal site and forum: a compact masthead, clear date columns, a
profile box, links that look like links, and visible section rules. Its cream,
ink and oxblood palette makes reading comfortable without pretending to be
vintage software.

The **Umbrella** theme is an original, Umbrella-inspired biotech dossier. It uses
black, bone white, warning red and clinical rules. The straight borders,
classification strip and tightly set metadata make pages feel filed and examined.
It has no copied logos, trademarks, game art or affiliation claim.

The **Forerunner** theme is an original, Halo Forerunner-inspired archive. Dark
basalt, pale stone, cyan light and angular panel joins evoke a very old, precise
system. The glow only marks current location, focus and active controls, so it
helps orientation instead of becoming a blue-neon effect.

Design dials: ENERGY 3 / RHYTHM 4 / MOTION 1. Density is intentional: the page
should show where to go and what has changed without using empty space as a
substitute for structure. Movement is limited to short state changes. Every
visual device serves navigation, reading order, or the selected theme.

Acceptance: a visitor can reach an authored post or source-backed project in two
clicks from the home page; each of the seven browser-verified Udemy courses has a
real detail page; every navigation destination resolves; no course or repository
fact becomes an invented achievement. CSS and JavaScript remain external. The
site stays usable with keyboard navigation, high contrast and narrow screens.

Authored Markdown and saved data are inputs, not implementation. This directory's
builder, templates, styles and JavaScript are new. No V5 application module is
imported. V5 remains available as a content and recovery reference while this
successor is verified.

Budgets: no server at hosting/runtime, no third-party browser requests, no remote
fonts, combined first-party CSS/JS under 45 KiB uncompressed. Offline source
builds use the existing pinned Markdown/YAML libraries. Windows and Linux CI keep
parity; local results describe Windows only until CI runs.

Public source selection: owned course titles, instructors and progress were
explicitly requested for portfolio context. No account identifiers, tokens,
receipts, ratings or study streaks are published. Private repositories are
excluded from automated snapshots. Local AI can draft a review, but it cannot
publish facts or replace authored writing.
