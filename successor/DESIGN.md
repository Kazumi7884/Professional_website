# Kaz's personal website: restored original direction

This is a personal internet home and learning notebook, not a recruitment landing page. The professional background is accessible through About, but it does not dominate Home or the navigation. Technical writing and personal blogs are separate.

## Information architecture

The original April 2026 topic contract is restored: Angular, ASP.NET, Bash, C#, CSS, Cybersecurity, Data Analytics, HTML, JavaScript, PowerShell, Python, R, React, Ruby, Ruby on Rails and SQL. Each has an overview and its own posts, projects and resources. Software development is a signpost only. Subject directories are grouped by purpose, not by a generic course funnel.

Markdown in content/learning/<subject>/posts/ is the owner of technical writing. Project records in projects.json have one canonical subject-owned route; earlier career URLs redirect there. Course details remain available as reviewed resources. The personal Steam study remains at its authored personal URL and is cross-linked, not copied into a technical blog. No placeholder exercise is presented as completed work.

## Visual identity

- Balanced restores the retained V5 ink, purple, blue and pink palette rather than the cream Forum redesign. Compact editorial rows and personal-site boards are the default composition.
- Halo / Forerunner uses the existing dark archive, cyan structural seams and angular panel framing.
- Resident Evil uses the existing Umbrella-inspired clinical file treatment, warning red and dossier-like headings.
- The themes retain their persisted identifiers; the visible labels reflect the original theme request.
- Vertical falling glyphs and horizontal signal bars restore the requested identity motif. CSS-only movement is decorative, optional, independently switchable and disabled for reduced-motion users. No external fonts, new artwork or third-party browser assets are required.
- Authored posts use a compact author column and bordered reading surface inspired by classic forums rather than modern portfolio cards.

Design dials: ENERGY 3 / RHYTHM 3 / MOTION 2 (decorative motion can be turned off). Preserve the user's authored voice and meaningful route hierarchy. These are original-inspired implementations, not a claim that all historical assets have been recovered pixel for pixel.

The public build remains static HTML, external CSS and JavaScript, with a pinned Python build and a separate local writing desk. Search, accessibility, safe Markdown handling, historic URLs, offline behaviour and the 45 KiB CSS/JS budget must remain intact. The optional original music player opens a separate tab for uninterrupted playback; it never starts automatically. The audio is not precached.

No invented projects, achievements, personal posts, course progress or public accounts. Empty subject subpages are explicit, excluded from search and sitemap until populated, and remain reachable from their subject hub.

## Approved Kaz composition (24 November 2026)

The owner's approved concept uses a compact personal-home masthead with the KAZ
wordmark, a horizontal signal strip, a welcome panel, two navigable boards for
Learning and Personal, separate recent-entry lists, and an author/utilities
sidebar. The monogram is a typographic initial, not a fabricated avatar.

Each subject has a heading, four locally active tabs, a published-entry board
and related resource/project sidebars. Posts have a title bar, author/date
gutter, readable code and same-subject older/newer navigation. On phones these
columns stack in reading order; at ultrawide sizes the central shell remains
bounded to avoid excessively long lines.

Personal layouts follow their content: Steam chart figures, compact anime
catalogue rows, Phasmophobia field records, a dated hardware spec sheet and a
chronological journal. Do not invent imagery or publish information from private
conversations. The three themes use distinct panel materials, headings and
structural seams while keeping the same functional navigation.

Style source order: theme-tokens.css, site.css (shared foundations), themes.css
(theme materials), sections.css (content layouts). The builder assembles one
external stylesheet to retain the existing request/offline budget. Design dials
remain ENERGY 3 / RHYTHM 3 / MOTION 2; decoration never takes precedence over
reading, and motion is optional. These directions are the accepted reference,
not a mandate to add more ornamental features.
