## Purpose

I wanted to understand patterns in my own Steam library rather than present a generic demonstration dataset. The analysis looks at playtime, critic and user scores, release years, tags, platform support, game modes and Steam Deck compatibility.

## My contribution

- Exported and processed my Steam library data offline.
- Generated the chart set using Python, Pandas, Matplotlib and Seaborn.
- Selected the questions each chart should answer and wrote the accompanying explanations.
- Published the results as optimised static WebP images so the site remains fast and private.

## Results

The finished set contains fifteen visualisations, including top games by playtime, playtime distribution, hours by release year, score distributions, tags, platform support and Deck compatibility.

## What it demonstrates

This is a modest, explainable project: acquiring a personal dataset, transforming it, choosing useful comparisons and communicating the results clearly. It does not depend on a backend or live access to a Steam account.
