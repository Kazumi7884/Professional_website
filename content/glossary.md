Quick definitions for recurring terms used across the site.

## Terms

### CLI

Command Line Interface for running tools and scripts.

### State management

How app data is stored and updated predictably.

### Refactor

Improve code structure without changing behaviour.

### Schema

Contract that defines expected JSON structure.
