Frameworks are here to demonstrate modern front-end skills while keeping the site intentional and navigable.
I treat them as “islands”: used where they help, not where they add complexity.

## React

Useful for interactive widgets, dashboards, and reusable UI. It’s common in industry and a strong way
to show component thinking and state management — without converting the entire site into an SPA.

[Go to React track](/learning/react/)

## Angular

A structured framework that demonstrates TypeScript skills, routing concepts, and enterprise patterns.
It’s useful for showing I can work within opinionated architectures.

[Go to Angular track](/learning/angular/)

## ASP.NET

Back-end and full-stack capability in the C# ecosystem. Even if this site stays static-first, ASP.NET is
important for future backend work and deployable apps.

[Go to ASP.NET track](/learning/asp-net/)
