These languages are here because they map directly to the kinds of roles and projects I’m aiming for.
Each one has a purpose on this site — not just “learning for learning’s sake”.

## C#

Strong for back-end work (ASP.NET), tooling, and structured application development. It’s a key language for
enterprise work and helps me demonstrate clean architecture, typing, and maintainability.

[Go to C# track](/learning/c-sharp/)

## Python

Great for automation, scripts, and data work. I use it for tooling around the site (validation, release checks),
and for building small utilities that make projects easier to manage.

[Go to Python track](/learning/python/)

## JavaScript

Essential for the web. I use JavaScript in a “static-first” way: progressive enhancement, small widgets,
and clean client-side behaviour without turning the whole site into a heavy SPA.

[Go to JavaScript track](/learning/javascript/)
