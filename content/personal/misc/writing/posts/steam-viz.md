## About These Visualizations

I generated these visualizations from my Steam library data to
better understand my gaming habits, preferences, and collection.
Each chart tells a different story about the games I own and
play.

The data includes playtime statistics, critic and user scores,
genre tags, platform compatibility, and release year
information. All visualizations were created offline and
uploaded as static images.

## Data & Tools

### How These Were Created

These visualizations were generated using Python with libraries
like Pandas, Matplotlib, and Seaborn. The data was exported from
Steam and processed offline to create these static charts.

This approach keeps the page lightweight and fast-loading while
still providing detailed insights into my gaming library and
habits.

All images are in WebP format for optimal file size and loading
performance.

### Insights & Takeaways

- Clear visibility into which games get the most playtime
- Understanding my Steam Deck compatibility situation
- Exploring the relationship between ratings and actual play
  behaviour
- Seeing genre preferences and collection trends over time
- Platform and multiplayer capability overview
