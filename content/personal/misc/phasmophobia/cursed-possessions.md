This page is for cursed possessions. These are powerful tools, but
they cost sanity and can accelerate hunts. I treat these as optional
tools, not required steps.

## List

- Music Box
- Ouija Board
- Voodoo Doll
- Haunted Mirror
- Summoning Circle
- Monkey Paw
- Tarot Cards

## Basic safety notes

- Plan an exit route before using any cursed item.
- Keep lights and hiding spots in mind if you are already low
  sanity.
- Use them after you have set up core evidence tools where possible.
